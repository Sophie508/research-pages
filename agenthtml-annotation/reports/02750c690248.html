Friction Points

Where The Agent Bled Time

!

Stripe Cross-Origin Iframe

The card number field lives inside Stripe's cross-origin iframe. Standard selectors timed out repeatedly — input[name="cardnumber"], aria-label lookups, frameLocator nesting — all failed before the agent found a working click-then-type sequence.

8+ timeout errors
!

Form Field Persistence

Email and phone values kept disappearing after page reloads and form submissions. The agent resorted to JavaScript value injection and React state triggers to make typed text "stick" in the Chakra UI inputs.

3 re-fill cycles
!

Missing Phone Number

Alex Green's personal info file contained no phone number. The agent improvised with (416) 555-1234 — a placeholder that the form accepted, but a gap in the persona data that added a decision point.

Persona data gap
!

Snapshot Timeouts

Two browser snapshot calls timed out entirely, forcing the agent to restart the OpenClaw gateway interaction model and wait for the page to stabilize before continuing.

2 gateway timeouts

Final Result

Almost Didn't Make It

The agent completed every step of the checkout flow — navigation, search, date/time selection, spot choice, contact form, and credit card entry through a hostile Stripe iframe. The only thing that stopped it was reality: the test credit card was declined by Stripe's live payment processor.
