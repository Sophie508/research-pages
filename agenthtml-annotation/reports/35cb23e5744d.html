What the filter blocked

The agent first reconstructed the sanitizer's behavior from the case trajectory. The script removed obvious executable containers and deleted attributes whose names began with on.

Script containers

<script> tags were removed regardless of type, so inline script and SVG script attempts did not survive.

Embedded documents

frame, iframe, object, and embed were filtered out as high-risk HTML containers.

Event attributes

Direct handlers such as onload, onerror, and onmouseover were stripped when they appeared as parsed tag attributes.

Why it worked

The solution depended on a parser differential rather than an unfiltered normal event attribute.

01

Sanitizer interpretation

BeautifulSoup treated the entire <!-->...--> sequence as comment content, so the embedded <img> was not visited by the tag and attribute removal logic.

02

Browser interpretation

The browser's HTML parser handled the malformed comment opener differently enough that the image element became active document markup.

03

Automatic execution

The image source x failed to load, causing the surviving onerror handler to fire without user interaction.
