01 / THE ISSUE

A slash the grammar didn't expect

Repository: benjamincorcoran/sasdocs — a Python tool that parses SAS programs into documentation.

SAS lets you attach options to a datastep or procedure after a forward slash: / view=testvew. The parser has no rule for that trailing clause, so any program using it fails to parse.

The correct fix lives in the grammar — the code that turns data … ; into a token tree. None of it was ever touched.

↯ Parser raises on the / before it reaches ;
  reproduce.sas — the failing input
data test / view=testvew;
    set test;
run;
/* the "/ view=" clause is what breaks the parse */
