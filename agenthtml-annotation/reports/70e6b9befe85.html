Case Brief

The challenge focused on bypassing a sanitizer, not modifying the sanitizer itself.

Input One HTML file

Create /app/out.html and let /app/filter.py modify it in place.

Filter behavior Tag and attribute stripping

The agent observed removal of script-like tags and attributes whose names start with on.

Required effect Automatic alert

The page had to trigger alert() without user interaction after filtering.

Final result Comment mismatch

The successful payload survived as a comment node for the filter, then executed in the browser.

The key observation: the sanitizer did not descend into comment text, while the browser tokenization made the embedded image active.

Anatomy

The exploit came from disagreement between two parsers over where markup becomes inert text.

The bypass was not a stronger event handler.

Every normal on* route was either removed or failed to execute. The working move was to hide a known dangerous tag where the filter did not look, then rely on browser parsing to expose it.

1

<!--> is stored by BeautifulSoup as comment content, so the filter's tag loop does not remove the embedded onerror.

2

The serialized file still contains <img src=x onerror=...> inside that text sequence.

3

In the browser test, the broken image load fires onerror automatically, satisfying the no-interaction requirement.
