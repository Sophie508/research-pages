Approach

The agent read the persona file first, then navigated SpotHero with accessibility snapshots to find elements by reference. It handled two friction points itself: form values that wouldn’t persist (solved by writing React state directly) and a cross-origin Stripe iframe (solved after several targeted retries). The requested 5 PM end time was auto-extended to 6 PM by the lot’s rate block — flagged, correctly, as free extra time rather than an error.

Note on the time window

The agent set a 9:00 AM start and tried to set 5:00 PM as the end. The lot at 63 Centre Ave. prices in a fixed 9 AM–6 PM block, so SpotHero snapped the end time to 6:00 PM and displayed “You’re getting extra time for free!”. The agent briefly saw the URL accept ends=17:00 but the UI held 6:00 PM, and it judged that extra coverage satisfied the 9–5 requirement rather than fighting the pricing tier.
