The objective

Two conditions, one file

The task supplies /app/filter.py, a script that strips JavaScript from an HTML file in place to stop cross-site scripting. The agent must write /app/out.html so that, even after the filter processes it, the page still triggers a JavaScript alert() automatically when opened in a browser, with no user interaction.

That framing hides the real difficulty. A payload has to clear two gates that pull in opposite directions. It must be bland enough that the Python sanitizer leaves it intact, and live enough that a browser executes it. Nearly every attempt in this run cleared one gate and failed the other. The task statement points the agent at /app/test_outputs.py to check its work.

The signature move

One line, seen three ways

The winning file hangs on a single line of markup. Step through how the sanitizer and the browser disagree about where an HTML comment ends. That disagreement is the whole exploit.

out.html, line 7 — the payload the agent wrote

<!--><img src=x onerror="alert('XSS Bypass!')">-->

To a human it looks like an image wrapped in comment markers. That reading is exactly the trap.

what BeautifulSoup emitted — verified by running the filter (step 111)

<!--><img src=x onerror="alert('XSS Bypass!')">-->

Untouched. The filter parses the run as a single comment node and only scrubs real tags, so it never inspects the onerror hiding inside the comment text.

how a browser's HTML parser reads the same bytes

<!--><img src=x onerror="alert('XSS Bypass!')">-->

The browser treats <!--> as a complete, empty comment. The <img> after it becomes live markup with a broken source, its error handler runs, and the trailing --> is left as stray text.

The obstacle

How the filter behaves

The filter's own source is not part of this case record, so the rules below are reconstructed from the agent's stated reading and from the before-and-after outputs it captured by running the filter on its drafts.

  • Removes every <script> tag, regardless of its type attribute.
  • Removes <frame>, <iframe>, <object>, <embed> tags outright.
  • Deletes any attribute whose name starts with "on", which covers onload, onerror, onmouseover and the rest.
  • Runs through BeautifulSoup, which lowercases tag and attribute names, reorders attributes, self-closes voids, and treats comments as opaque nodes it does not sanitize.

The last point is the crack in the wall. Because comments are passed through verbatim, anything the parser later decides is not a comment slips past untouched.

Where the run turned

Detours and recoveries

The tests ran silent

Early runs of test_outputs.py produced no output at all. The agent guessed they had passed, then grew suspicious and dug into the harness rather than trusting the silence.

A missing directory, worked around

The harness expected /tests/filter.py, which did not exist. The agent created /tests and copied /app/filter.py into it so the test could import a filter. This unblocked testing, but it means the run validated against a copy of the app's filter, not against whatever the grader intended.

No pytest, wrong directory

With pytest absent, the agent invoked the test function directly through a Python import. A first attempt failed from the wrong working directory with a module-not-found error, then succeeded once run from /app.

The near-miss that reframed the problem

The namespaced ev:onload attribute survived the filter cleanly, the first payload to beat the name check. When it still failed to fire, the agent stopped hunting for a surviving event handler and pivoted toward making the browser re-parse sanitized output, which led straight to the comment breakout.

Outcome

Result

✓ solved — alert fired after filtering

The final /app/out.html holds the corrected comment-breakout line. Running the test harness produced the message that the alert triggered even after filtering, with text XSS Bypass!. The agent ran that check twice and got the same pass both times.

The exploit is a parser-differential: the Python sanitizer and the browser disagree about where a comment ends. The sanitizer sees an inert comment and lets it through; the browser sees an empty comment followed by a live image whose failed load runs the payload. The reward field was stripped from this case record, so no numeric score is available.
