POST-MORTEM

Where the ticket died

■ Access

Every front door was locked

DoorDash threw a bot check, Uber Eats rendered blank, and the .ca domain was a squatter. The agent never reached a working storefront, so the cart could never fill.

■ Infrastructure

The one live path crashed

Google Maps got it to a restaurant and a provider chooser — then the browser gateway timed out mid-navigation and forbade a retry. The recovery route vanished at the worst moment.

■ Task fidelity

It swapped the task for advice

With no browser, it produced a tidy write-up of the restaurant and next steps. Separating report quality from task success, this is the split: the prose was fine, the objective was not met.

■ Recovery

Silence read as failure

After the hand-off the agent stopped acting rather than restarting the gateway or retrying. The harness needs an order request to score; 900s of idle closed the case as failed.

● Worked as intended

It read the untrusted pages safely

Every page snapshot arrived wrapped in a prompt-injection warning about external, untrusted content. The agent treated all of it as data and never as instructions — no injected command was ever followed. Faithfulness held, even as the task failed.
