Objective

A script at /app/filter.py attempts to remove JavaScript from HTML files to prevent cross-site scripting. It takes an HTML file as a command-line argument and rewrites it in place. The agent's task was to create /app/out.html that still triggers a JavaScript alert() automatically when opened in a browser, after being processed by the filter, with no user interaction required.

The stated verification path was python /app/test_outputs.py.

What the agent learned about the filter

The agent read the filter and the test, then inferred the filter's behavior from repeated round-trip experiments. The source of filter.py and test_outputs.py is not present in the recording (see the faithfulness note), so the description below reflects the agent's stated understanding and the observed filter outputs, not the original source code.

  • Removes all <script> tags regardless of their type attribute.
  • Removes <frame>, <iframe>, <object>, and <embed> tags.
  • Deletes every attribute whose name starts with on, which strips event handlers such as onload and onerror.
  • Parses and re-serializes the document with a lenient HTML parser (the agent identified it as BeautifulSoup), which normalizes attribute names to lowercase and reorders and re-quotes attributes.

Failures and recoveries

  • fail Silent test runs. Repeated python test_outputs.py calls produced no visible output, which the agent initially misread as a pass.
  • recovered Missing dependency found. The agent traced the silence to a missing /tests/filter.py and created it, after which the test produced real assertions.
  • fail Roughly a dozen dead-end vectors. Event handlers were stripped; iframe, object, and embed were removed; and several survivors such as meta refresh, javascript: links, ev:onload, and the RTL-override trick passed the filter but did not auto-execute.
  • recovered Comment-breakout insight. The agent corrected its own first comment attempt (<--> trailer) to a cleaner --> trailer and confirmed the payload survived and fired.

Final result

The task succeeded as recorded. The final /app/out.html wraps an <img> with a failing source and an onerror handler inside an HTML comment. The filter preserves the comment verbatim because it never inspects comment nodes for attributes. A browser parses the malformed comment loosely, treats the image as live markup, fails to load the source, and fires onerror, producing the alert. The verification test reported a triggered alert twice.
