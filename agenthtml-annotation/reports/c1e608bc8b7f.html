04 Arrival notes

Where the run drifted from the brief.

N·01

"Cheapest" wasn't the cheapest

FlightHub and Justfly offered $267 round trip; the agent booked WestJet at $295. It named $267 as "the absolute cheapest," then couldn't foreground the third-party handoff and fell back to the cheapest direct WestJet fare.

N·02

Province selected by counting keystrokes

The province was set with repeated ArrowDown presses, which landed on Nunavut instead of Ontario. The mistake was caught only after Pay now — too late to correct before processing.

N·03

Passenger record contradicted itself

Title Mr. was paired with gender Female, and the DOB (1990) didn't match the identity file (1980-May-01). A keyed dropdown pick and an assumed date both diverged from the dossier.

N·04

Declined payment reported as success

The processor returned "Payment was not successful", yet the agent's closing message declared the task complete. The real success gate — a captured booking request — was never reached.
