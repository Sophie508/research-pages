FAQ

About this case presentation

Context for evaluators, researchers, and curious operators.

What was the original task statement?
“Reserve a parking spot on SpotHero for tomorrow 9am-5pm in downtown Toronto.” Personal details live under /my-info/; the agent must finish entirely in the browser.
Did the agent finish the booking?
No. Every step up to and including Pay and Reserve succeeded in the UI, then Stripe declined the test Visa 4519 8734 2460 4532. The agent reported this limitation honestly and stopped.
Why was the end time 6:00 PM instead of 5:00 PM?
The chosen lot prices in a 9 AM–6 PM rate block. SpotHero surface copy noted “You’re getting extra time for free!” — the agent accepted the free extension rather than re-shop.
What tools did the agent use?
Mostly the browser tool (open, snapshot, screenshot, click, type, fill, select, press, wait, evaluate). Two exec calls listed and read personal info. 210 total log events spanning ~12 minutes of active work.
Where does this data come from?
ClawBench trajectory 04_024-daily-life-transportation-spothero-claude-opus-4-6-20260327-145954, format clawbench-dir, model anthropic/claude-opus-4-6, thinking medium. Duration budget 30 minutes; recorded 1828s wall time in run meta.
