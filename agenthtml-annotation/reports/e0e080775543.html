Failure Analysis

Root Causes of Failure

Three independent infrastructure problems compounded to prevent task completion.

1
Bot-Detection on All Delivery Platforms
DoorDash.ca, DoorDash.com, and Uber Eats all triggered a security notice that suppressed DOM snapshots. The agent could take screenshots but could not read interactive elements, making click-based interaction impossible on these sites.
2
Browser Gateway Timeout
After navigating to Google's order-provider chooser page, the OpenClaw browser gateway timed out. The error message explicitly warned against retrying. This permanently ended any browser-based action in the session.
3
Web Search Unavailable
The web_search tool (Brave) requires a pre-configured API key which was absent from the environment. This blocked the agent's final fallback of finding direct restaurant ordering links.

What is ClawBench and the trajectory format?
ClawBench is a web-agent benchmark that records agent sessions in a clawbench-dir format. Each run consists of an agent-messages.jsonl file (one JSON object per line) containing session, model_change, thinking_level_change, custom, and message entries. The message entries carry role (user, assistant, toolResult) and content blocks (text, tool_use, tool_result, thinking, image).
What browser tools did the agent use?
The agent used an OpenClaw browser (Chromium via CDP on port 9222). Available actions included start, navigate, screenshot, snapshot (accessibility tree), act (click, type, press, wait). Snapshot calls were the primary mechanism for reading page state — these were blocked by bot-detection on all major delivery platforms.
Why did the agent try DoorDash before Uber Eats?
The task only specified Uber Eats in the benchmark metadata (sites_involved: ["ubereats.com"]), but the task instruction itself was delivery-platform agnostic: "Order delivery… note 'no peanuts'". The agent chose to try DoorDash first as a popular alternative, then pivoted to Uber Eats (the intended target). This is a reasonable but off-spec behavior — the benchmark expected the agent to use Uber Eats directly.
