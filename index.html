Baseline Reproduce

Four text systems delivered on a fixed slice, live web search instead of the knowledge store. HerO2, SANCTUARY, AIC CTU and InFact on AVeriTeC dev 0–99, all on Gemma via OpenRouter as an adapted reproduction: 400 of 400 terminal records, of which 391 ok, 5 without evidence and 4 retrieval failures. Browse every claim with the gold label, open a system's questions, answers, sources and reasoning, compare two systems side by side. Label accuracy is 48–61%, none above the 63% always-Refuted baseline; the evidence score is the legacy Hungarian-METEOR, not EV2R. The two image-text systems are deferred, so the six-system scope is not complete.

AVeriTeC + AVerImaTeC Review

Our pipeline on the two datasets that have ground truth. AVerImaTeC val, 108 claims and 379 evidence items from the 2026-08-30 run after the new URL stage: each statement keeps the link it got, article hyperlink first and dated external search second, with the verifier's verdict shown but not deciding; only statements with no candidate link at all were dropped, 18 of 397. Every card carries its own official-protocol EV2R evidence score; over the set it is R 0.733 / P 0.621, level with the run before the URL stage, because EV2R scores statements rather than links. AVeriTeC's 20 claims are the earlier text-only run and are labelled as not yet through the new URL stage.

Deep Fake Filter

The VeriTaS claims whose media VeriTaS itself judged fabricated. One selection rule: the claim carries media, and at least one medium's authenticity label from the VeriTaS four-model ensemble is "fabricated" at any confidence, tagged AI-generated, Manipulated or Forged in VeriTaS's own terms. Real media in a false context is excluded; that is a contextualization failure, not a fabrication. The publisher's own rating and the contextualization label are shown alongside as independent signals but did not select. No evidence extraction has been run on this set yet; the page is for looking at what the set contains.
